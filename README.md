# DSA in 2026

A practical guide to data structures & algorithms for when AI writes the code.

**Live site:** `https://pavittarx.github.io/dsa-guide/`

A single self-contained static HTML page (inline CSS, no build step, no
dependencies), responsive and light/dark-mode aware.

## Publish to GitHub Pages

1. Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
2. Select branch **`main`** and folder **`/ (root)`**, then **Save**.
3. Wait ~1 minute — the site goes live at the URL above.

The included `.nojekyll` file tells GitHub Pages to serve the HTML as-is
(skipping Jekyll processing).
